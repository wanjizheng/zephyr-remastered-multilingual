# 2026-10-03 游戏更新适配（v0.5.4，本地交付）

支持 Steam build **25674418**。旧版 build 25418345 的补丁不能直接用于本次更新：资源包名称、Addressables 目录、部分对象和 IL2CPP 元数据位置已发生变化。

本轮以经 Steam 完整性验证的新版原文件重新构建三语载荷，而不是放宽旧版哈希检测。保留此前英文 r9 的译文修订、Libre Baskerville 对话字体、Inter 界面字体以及开场、日记、人物姓名和窄按钮排版修复；简体和繁体保持独立选择。

## 三语同步内容

- 任务列表：全部／仅主线任务。
- 遭遇频率：较少／默认／频繁／更频繁／非常频繁。
- 无视弹药消耗。
- XP 获取倍率：默认／2 倍／5 倍／10 倍／始终最大。
- 剑类及其他装备分类、存档失败／损坏提示。
- 新版将部分装备与系统说明的 `/n` 改为实际换行，译文同步采用对应换行方式。
- 补译游戏程序内的 Steam 连接失败提示、确定按钮和新增物品文字。

官方本次更新的战斗逻辑、特效、语音音量、XP UI、新增选项组件及武器 SubType 字段均从新版原文件保留。安装器不改写 GameAssembly.dll、游戏 EXE、Steam 配置或存档；GameAssembly.dll 新增为只读版本校验依赖。

## 安装与恢复

从 Steam 游戏库启动游戏。直接启动 EXE 时，游戏可能显示 Steam 未运行或连接失败的提示；此提示不能作为补丁加载失败的证据。

关闭游戏，使用新版工具选择语言后安装。如果 Steam 更新后仍有旧补丁残留，先验证游戏完整性，再重新安装新版补丁。安装器识别到完整的新版原文件时，会保留旧版本备份，并建立经哈希验证的新版备份。仍然拒绝未知版本和非受管理的修改文件。

## 验证范围

三语资源独立重建、Unity 原生 CRC 与强制资源加载、文本和对象回读、新增界面字形覆盖、旧备份升级、语言切换、故障回滚，以及原生程序集更新后的拒绝安装均记录在本轮审阅包中。

启动／菜单实机结果以审阅包的 runtime-verification.json 为准。99 级战斗结算、弹药消耗、XP 倍率、必杀技切换、全部地图和剧情动画的完整游玩效果，仍需游戏内进一步验收。

## 本次新增快捷操作

- M／手柄 L2（LT）：普通小地图与全屏地图切换，不关闭小地图。
- Ctrl：2 倍速；Shift：4 倍速（另保留游戏原有小键盘快捷键）。
- E／手柄 R3：行动前防御，移动后结束回合。

以上操作由新版官方游戏提供，补丁保留其逻辑；快捷键效果不以静态资源检查代替实机验证。
