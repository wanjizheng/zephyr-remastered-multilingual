# 英语常规字体 r8：对白与章节标题统一

按用户看过预览后的选择，将英文对白与章节标题都改为 **Libre Baskerville Regular，常规字重 400**，取代对白的 Great Vibes 和标题的 Berkshire Swash。普通界面、人物名、简体和繁体保持原样。

本轮只调整字体和排版，完整保留 r7 的 22,507 个英文文本字段，包括此前优化及三处自然度补修。对白的 16 个已确认组件采用字号 34、字距 0、行距 0；标题保留已有组件字号，通过字形 scale 保持先前的大写字母有效高度。新字形像素放入空白区域，保留此前图集像素与非拉丁字符。

对白继续使用独立字体资源；标题同时更新默认资源包和原生 sharedassets0 的 Batang 字库。两者使用同一来源的正体常规字形，没有连笔或装饰花体。全部当前英文字符均为可打印 ASCII 或控制空白，95 个字符由此字体覆盖。

官方变量字体及许可未修改，来源、哈希见 `font-sources.json`。为烘焙字形将其固定在 400 字重，静态派生字体及独立字体资源内部命名为 **Zephyr Book**，遵守 OFL 的保留字体名称要求；字形来源仍是用户选定的 Libre Baskerville。派生步骤和校验见 `static-font-derivation.json`，完整许可见 `fonts/LibreBaskerville-OFL.txt`。

`字体方案.png` 采用实际输出字形、材质和对白配置进行隔离渲染，对比用户截图中的同一句对白并展示常规章节标题。测试框为 1180×170；背景、示例章节标题与画布放置是示意，不是游戏截图。四组对白（含三行文本）和一组标题合计九张前后样本均记录边界状态，具体结果见 `proof/offline_proof_result.json`。游戏内动态布局和游玩效果仍待玩家验收。

工程检查包括：21 个资源重建、15 个 Unity 原生 CRC 和加载验证、独立第二次重建、全部 22,507 文本字段回读、三份字体表及图集、16 个对白组件配置、冻结安装器中的 r7 同版本升级、三语切换和隔离原版还原。最终通过状态以 `final-verification.json` 为准。

为避免 F 盘空间再次用尽，大型构建与隔离测试副本放在 C 盘本轮专属临时目录，项目的 `runtime` 是指向该目录的联接。它们不进入审阅 ZIP，也不改变真实游戏或原版备份；完成包与全部审阅证据仍存放在 F 盘项目中。

当前工程源码和英文载荷将包含本轮修改，工作台重新生成安装包会采用它们。安装器版本仍为 0.5.3，载荷哈希识别同版本更新。未安装到真实游戏，未提交或发布 GitHub。
