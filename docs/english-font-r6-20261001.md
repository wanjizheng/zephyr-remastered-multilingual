# 英语古典小说字体 r6（2026-10-01）

在独立复核通过的 r5 文本基础上，将英文剧情对白改为 EB Garamond Medium（500），保留现有字号、文字颜色及大写字母高度，收紧 16 处对白字符间距，并加入新字体的字偶间距。章节标题共用字体，也显示新的古典字形；普通界面字体及简繁字库不变。

本轮英文文本与 r5 的 22,507 个字段一致。修改仅涉及两处字体表、两处图集与 16 处对白组件的字符间距。完整资源重建、15 个原生 CRC、字体与字段回读、冻结安装器的 r5 同版本升级和三语切换还原均进行验证，结果见配套完整审阅包的 `final-verification.json`。

字体遵循 SIL OFL 1.1，许可随程序放在 `licenses/EBGaramond-OFL.txt`。只携带独立烘焙的授权字形和声明式修改，原始游戏资源不随安装包分发。

当前源码及直接工作台构建包含本次修改；安装器版本仍为 0.5.3。对比图为隔离 Unity 渲染，背景、样例文字和 1180×170 测试矩形用于比较；真实游戏动态布局、显示与游玩尚待验收。未安装到真实游戏，未提交或发布 GitHub。
