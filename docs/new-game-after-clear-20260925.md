# 通关后再次开始新游戏：三语补丁源修复

截图中的“继承通关记录”窗口来自 `global-metadata.dat` 的 IL2CPP 内嵌韩文字符串。三语 `SystemTexts_RE_KO` 表中虽已有 `s00001051` 等译文，实际窗口走的是内嵌字符串，所以改文本表不能修复这张截图。当前安装目录中的简体资源包已含该表译文；本次没有写入游戏目录。

## 覆盖范围

内嵌字符串索引 `21181` 是截图正文。索引 `21182` 和 `21184` 是“不继承／继承”选项的说明，`21196` 和 `21199` 是开始／继续游戏说明；共五条新游戏流程文案。`21171` 和 `21167` 分别是截图的“是／否”，这两个按钮词可能在其他确认框复用，所以三语均采用通用译法。原版内嵌字符串中包含“通关记录”“新游戏”或相邻的开始／继续说明的条目均已核对。

| 索引 | 简体 | 繁体 | English |
|---|---|---|---|
| 21181 | 是否继承此前的通关记录（已通关{0}次），/n开始新游戏？ | 是否繼承此前的通關記錄（已通關{0}次），/n開始新遊戲？ | Carry over your clear data ({0} completions)/nand start a new game? |
| 21182 | 不继承此前的通关记录，/n从头开始新游戏。 | 不繼承此前的通關記錄，/n從頭開始新遊戲。 | Start a new game/nwithout carrying over clear data. |
| 21184 | 继承已保存的ELD、物品和装备，/n开始新游戏。 | 繼承已儲存的ELD、物品和裝備，/n開始新遊戲。 | Start a new game with saved ELD,/nitems, and equipment. |
| 21196 | 从头开始新游戏。 | 從頭開始新遊戲。 | Start a new game from the beginning. |
| 21199 | 从最近的存档继续游戏。 | 從最近的存檔繼續遊戲。 | Continue from the most recent save. |
| 21171 / 21167 | 是 / 否 | 是 / 否 | Yes / No |

`/n` 是游戏内控制换行，`{0}` 是通关次数占位符；两者保持原格式。游戏安装时只从玩家自己的原版元数据重建，不包含原版完整资源。补丁保持元数据文件大小及其他节区起始位置不变，逐条校验原韩文；重排内嵌字符串区的偏移表并逐条回读。旧版已翻译的存档时间、跳过、原版模式提示等内容继续由原有操作生成。
