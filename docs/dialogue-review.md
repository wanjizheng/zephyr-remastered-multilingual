# 边玩边校对：让每一句对白更好

[English tutorial](dialogue-review.en.md) · [返回首页](../README.md) · [下载最新版](https://github.com/wanjizheng/zephyr-remastered-zh-cn/releases/latest)

一句更自然的对白、一个说得通的称呼、一处错字，都能让下一位玩家的冒险更顺畅。无需编程，也不必承担整章翻译；你可以只贡献自己在游玩中发现的一句话。简体、繁体和英文建议都欢迎。

## 1. 打开校对窗口

完整解压 v0.4.4 安装包，运行 `ZephyrChinesePatcher.exe`。在安装器中选好游戏目录及 CN／TW／EN，点击“对白校对”（英文界面为 **Dialogue review**）。校对可以在游戏运行时使用；安装或切换游戏语言则必须先退出游戏。

CN、TW、EN 决定校对的目标语言。顶部“游戏实况”是游戏正在显示的文字；右侧“语言包原文”是所选语言包的文字。两者语言不同时，先确认你打算改哪一种语言。

## 2. 在游戏中遇到一句值得改的台词

让对白完整显示，稍停一下。助手会尝试读取当前台词，在“最近 20 句”中显示可定位的记录。选择这句，查看右侧原文。

“跟随最新对白”开启时会跟着游戏切句；点击历史记录或开始编辑时会停止跟随，让你安心写完。写完后可以重新勾选跟随。需要时可开启“置顶”。

## 3. 写下你的建议

点击“用原文起草”，或直接在“你的建议译文”里填写整句修改。原因可以很短，例如“这里是在对两个人说话，应为你们”“前一句说明她已经知道这件事”“英文直译不自然”。

只想指出问题也可以：填写“修改原因 / 说话人问题”，不必勉强给出新译文。尽量保留原意、人物关系和既定译名；有剧情依据时说明上下文。请标注剧透，不必贴出整段剧情。

修改后的条目保留在“已修改的台词”，不受最近 20 句列表的限制。同一句打字动画不会重复生成一排记录。三种目标语言的建议分别保留。

**这里记录的是修改建议，不会当场替换游戏里的文字，也不会改存档。** 维护者核对、采用并制作后续补丁后，玩家安装更新才能看到新的译文。

## 4. 关闭前导出

点击“导出修改包”，保存 ZIP。包内包含你填写的建议、原文及用于定位台词的版本信息，方便维护者准确查找。只导出有建议或说明的条目。

**本次校对记录仅保留在当前窗口会话中。关闭窗口后不会自动恢复，务必先导出。** 界面里的“已修改”不表示已上传或已永久保存。

## 5. 分享给社区

点击“预览提交”，检查内容，再点击“复制并打开 GitHub”。在网页中选择翻译校对建议，粘贴正文，附上刚导出的 ZIP，然后自行提交。也可以直接打开[翻译建议表单](https://github.com/wanjizheng/zephyr-remastered-zh-cn/issues/new?template=translation.yml)。GitHub 提交需要账号；本地使用和导出不需要。

可以按同一场景或同一类问题整理一批建议。先看看已有 Issues，重复问题可以在原讨论中补充。愿意的话写上希望使用的署名。我们欢迎讨论不同表达；最终是否采用，以原意、上下文、人物语气和全篇一致性为依据。

提交不会自动上传游戏文件，也不会自动合入补丁。请只附建议包和必要的截图，不要上传游戏资源、程序、存档或含个人信息的整份日志。

## 没有捕获到对白？

- **提示“读取已暂停”**：先让场景加载完，再点“继续读取”。跨场景时的短暂读取失败可能使本版停止轮询；不是所有漏句都意味着版本回退。
- **右侧还停在上一句**：查看“跟随最新对白”，或从最近列表手动选句；正在编辑时不自动切换是为了保护建议。
- **对白完整显示仍未出现**：当前版本并未覆盖全部显示路径。相同正文对应多个资源条目、安装文本与内置语言包不同、快速跳句等情况可能无法定位。请截图，记录场景及补丁版本，通过 Issues 手动反馈；不要为了提交而猜台词编号。
- **游戏版本不受支持**：更新补丁或报告游戏版本，不要强行继续读取。

校对助手会继续改进。你不需要先证明自己是翻译专家——把游玩中真正读不顺的那一句告诉我们，就是有价值的贡献。
