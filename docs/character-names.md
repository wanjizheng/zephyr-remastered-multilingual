# 人物译名对照：来源与使用范围

[返回首页](../README.md#人物译名对照)

这张表帮助玩家把老攻略中的人名与本项目译名对应起来，不评价每个旧译名的对错，也不据此合并人物身份。当前整理 32 项主要与补充姓名，未声称覆盖所有路人 NPC。

## 新译名如何确定

韩语栏采用项目已提取的韩文姓名；新版中文栏采用本项目生效术语决定，包含后续明确确认的“罗伯托·德·梅迪西”“卡塔莉娜”“米勒”，以及按资源拉丁名 `Lipnetz` 确定的“伊莎贝尔·利普内茨”。这些拉丁名字段不代表游戏存在可玩的英文版。

对照表仅整理既有译名，不改变游戏内翻译，也没有重新翻译已接受的全文。全文称呼仍根据原文使用：短称不强行扩写为全名，职务或称号不自动并入姓名。

## 旧译名的证据边界

旧中文版、不同地区版本、攻略转录和后来的玩家统一译名并不总是一致。因此首页使用“老中文版／旧资料译名”，而非声称每个名字都来自某一张 1998 年中文发行光盘。1998 年是原作年份，不能直接拿来确定某个中文发行版本的年份。

当前尚未逐项用旧游戏画面或说明书核实，来源分为：

| 标记 | 来源 | 能说明什么 |

## 容易混淆的地方

- **克里斯 / 克里斯蒂娜**分别对应 `크리스 / 크리스티나` 的显示形式。不能因为旧攻略常用一个短称，就把所有全名字段填成同一条。
- **梅迪西**沿用项目已经接受的短称；完整名为**罗伯托·德·梅迪西**。不会把旧草案中的“美第奇”再带回来。
- **圣女埃斯梅拉达**含称号。原文只出现人名时采用“埃斯梅拉达”。
- **莎伦·哈斯特 / 沙伦沪斯特**是旧资料异写，表内对应本项目“沙恩霍斯特”；不展开其与其他角色的身份关系。
- **卡特琳娜 / 佧他丽娜**来自旧玩家表的 `Kathrine` 项，作为旧名线索保留，仍需要旧版画面进一步核对。
- **“待核”不是漏译标记**：这些行已经有本项目的新译名，缺的是可信的旧版中文对应。

欢迎在 [Issues](https://github.com/wanjizheng/zephyr-remastered-zh-cn/issues) 补充旧版姓名截图和版本信息。请说明简／繁体版本、发行方或光盘信息（若知道）；不要上传整部游戏。
